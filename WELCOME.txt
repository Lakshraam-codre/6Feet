OPTION 1: Using Quick Start Script (Easiest)
─────────────────────────────────────────────
Linux/macOS:
  $ chmod +x start.sh
  $ ./start.sh

Windows:
  > start.bat

OPTION 2: Using Docker Compose (Recommended)
────────────────────────────────────────────
  $ cd agri-chatbot
  $ cp backend/.env.example backend/.env
  $ nano backend/.env  # Add your API keys
  $ docker-compose up -d

OPTION 3: Manual Setup (Python + Node)
──────────────────────────────────────
Backend:
  $ cd backend
  $ python -m venv venv
  $ source venv/bin/activate  # or venv\Scripts\activate on Windows
  $ pip install -r requirements.txt
  $ uvicorn app.main:app --reload

Frontend (New Terminal):
  $ cd frontend
  $ npm install
  $ npm start

Before starting, get these API keys:

1. OpenAI API Key
   → https://platform.openai.com/api-keys
   → Required for: LLM responses, chatbot intelligence

2. Africa's Talking API Key
   → https://africastalking.com
   → Required for: SMS, USSD, Voice channels

3. Weather API Key (Choose One)
   → OpenWeather: https://openweathermap.org/api
   → WeatherAPI: https://www.weatherapi.com
   → Required for: Weather alerts and forecasts

4. PostgreSQL (Optional if using Docker)
   → Docker Compose includes PostgreSQL automatically

📞 SUPPORT & TROUBLESHOOTING:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Issue: Port already in use
  → Kill process: lsof -ti:8000 | xargs kill -9

Issue: Database connection error
  → Check: docker-compose logs postgres

Issue: API keys not working
  → Verify in dashboard of each provider
  → Check rate limits and quotas

Issue: Frontend not loading
  → Check: docker-compose logs frontend
  → Verify REACT_APP_API_URL is correct

See docs/SETUP.md for detailed troubleshooting!
